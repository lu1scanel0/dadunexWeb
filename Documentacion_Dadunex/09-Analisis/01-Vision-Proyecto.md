# Visión del proyecto

## Nombre

Agroplan.

## Visión

Plataforma web para gestionar predios, cultivos, productos fitosanitarios, fertilizantes, inventario, aplicaciones, restricciones, carencias, costos e historial.

## Enfoque

Construido para Dadunex, preparado para múltiples empresas, accesible desde computador y teléfono, simple, modular y comercializable.

## Problema

La información se distribuye entre Excel, cuadernos y órdenes manuales, aumentando tiempo, errores y riesgo.

## Resultado

Centralizar la operación desde recomendación hasta ejecución e historial.
