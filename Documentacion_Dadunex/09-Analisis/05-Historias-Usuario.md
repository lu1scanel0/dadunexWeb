# Historias de usuario iniciales

## HU-001 — Crear empresa

Como superadministrador quiero registrar una empresa para habilitar configuración independiente.

## HU-002 — Asignar múltiples roles

Como administrador quiero asignar varios roles a un usuario para reflejar sus responsabilidades.

## HU-003 — Crear temporada

Como administrador quiero configurar fechas de inicio y término.

## HU-004 — Registrar predio

Como administrador quiero registrar un predio y sus datos.

## HU-005 — Registrar cuartel

Como administrador quiero asociar un cuartel a un predio.

## HU-006 — Mantener especies y variedades

Como administrador quiero crear y editar catálogos.

## HU-007 — Importar productos

Como administrador quiero cargar un Excel, revisar diferencias y conservar versiones.

## HU-008 — Registrar lote

Como responsable de bodega quiero ingresar proveedor, factura, vencimiento y costo.

## HU-009 — Recomendar aplicación

Como responsable técnico quiero recomendar una aplicación.

## HU-010 — Aprobar aplicación

Como usuario autorizado quiero aprobar o rechazar.

## HU-011 — Emitir orden

Como administrador quiero emitir una orden clara.

## HU-012 — Registrar ejecución

Como aplicador quiero ingresar cantidades reales.

## HU-013 — Descontar inventario

Como sistema quiero descontar consumo confirmado.

## HU-014 — Consultar historial

Como gerente quiero revisar historial por temporada y unidad productiva.
