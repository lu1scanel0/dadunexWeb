# Panel Administrativo — Módulos

## Dashboard

Indicadores, pendientes y accesos rápidos.

## Contactos

Listar, buscar, filtrar, revisar detalle, cambiar estado y agregar notas.

## Configuración

Parámetros generales, estados, datos de empresa, preferencias e integraciones.

## Usuarios

Crear, invitar, activar, desactivar y asignar roles.

## Roles y permisos

Un usuario puede tener múltiples roles. Los permisos se acumulan según las responsabilidades asignadas.

## Agroplan

Acceso integrado desde el panel, con código, build y despliegue propios.
