# Dadunex Web — UI/UX

## Principios

- claridad;
- confianza;
- enfoque B2B;
- navegación simple;
- diseño responsive;
- accesibilidad;
- tiempos de carga bajos.

## Identidad visual

Usar logo oficial, paleta institucional, tipografía consistente, fotografía real y llamados a la acción visibles.

## Jerarquía

Cada página debe responder:

1. quién es Dadunex;
2. qué produce;
3. cómo puede contactar un comprador.

## Formulario

Campos recomendados:

- nombre;
- empresa;
- correo;
- teléfono;
- país;
- tipo de consulta;
- mensaje.

Encabezado sugerido:

**Contáctenos**  
*Cuéntenos sus requerimientos. Nuestro equipo comercial le responderá a la brevedad.*

## Accesibilidad

- etiquetas asociadas;
- foco visible;
- navegación por teclado;
- contraste suficiente;
- textos alternativos;
- mensajes de error comprensibles.
