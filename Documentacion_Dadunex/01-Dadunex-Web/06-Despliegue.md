# Dadunex Web — Despliegue

## Flujo

1. actualizar rama estable;
2. ejecutar validaciones;
3. generar artefactos;
4. sincronizar con S3;
5. invalidar caché;
6. ejecutar pruebas postdespliegue.

## Controles

- enlaces;
- formulario;
- consola sin errores;
- responsive;
- imágenes;
- SEO;
- HTTPS;
- política de privacidad.

## Rollback

Conservar artefacto estable anterior, versionado de S3 y registro de releases.

## Pendientes

- nombre del bucket;
- ID de distribución;
- dominio;
- certificado;
- variables de API.
