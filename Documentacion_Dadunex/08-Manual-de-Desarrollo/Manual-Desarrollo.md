# Manual de desarrollo

## Repositorios

```text
DadunexWeb
DadunexAdmin
Agroplan
```

## Ramas

Para un desarrollador:

```text
main
feature/*
fix/*
```

## Commits

```text
tipo(alcance): descripción
```

Ejemplos:

```text
docs(agroplan): actualiza encuesta
feat(contactos): agrega filtro
fix(auth): corrige expiración
```

## Definition of Done

- criterios cumplidos;
- build correcto;
- pruebas;
- documentación;
- revisión manual;
- sin errores visibles.

## Versionado

SemVer: `MAJOR.MINOR.PATCH`.
