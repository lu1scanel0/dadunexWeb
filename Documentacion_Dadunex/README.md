# Documentación de la plataforma Dadunex

Este paquete separa la documentación de tres productos relacionados pero independientes:

1. **Dadunex Web**: sitio público corporativo y comercial.
2. **Panel Administrativo**: aplicación interna para gestionar contactos, configuración, usuarios y accesos.


## Estructura

```text
01-Dadunex-Web/
02-Panel-Administrativo/
03-Arquitectura-Compartida/
04-Infraestructura-AWS/
05-API/
06-Base-de-Datos/
07-Seguridad/
08-Manual-de-Desarrollo/
09-Analisis/
```

## Estados utilizados

- **Definido**: decisión acordada.
- **Propuesto**: recomendación técnica o funcional.
- **Pendiente**: requiere validación o levantamiento adicional.

## Principios

- separación de responsabilidades;
- arquitectura serverless en AWS;
- documentación versionada;
- seguridad por defecto;
- diseño modular;
- soporte multiempresa para Agroplan;
- bajo costo operativo;
- trazabilidad de decisiones y cambios.
